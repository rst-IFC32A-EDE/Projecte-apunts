HTML Básic

Estructura Basica

Un document HTML es basa en una estructura jeràrquica de etiquetes que defineixen les diferents parts d'una pàgina. Cada pàgina HTML segueix una estructura similar, començant pel < !DOCTYPE>, seguit de de les etiquetes < html>, < head>, < body>.

Etiquetes basiques

< title> Defineix el titol del projecte < h1> fins < h6> Son utilitzats per titols de text < p> S'utilitza per ficar paragrafs de text < br> Força el text a començar una linea nova & nbsp; Inserta un espai blanc que no es trenca entre linies

Anidament

Anidament es refereix a col·locar un element HTML dins d’un altre element. És important seguir correctament l'ordre de les etiquetes: la primera que s'obre és l'última que es tanca.

Atributs

Els atributs en HTML són elements que afegeixen informació extra a les etiquetes HTML per modificar-ne el comportament o l'aparença. Aquests atributs sempre es col·loquen dins de l'etiqueta d'obertura i segueixen el format nom="valor".

Text Formatat

< b> i < strong>: Negreta < i> i < em>: Cursiva < u>: Subratllat < strike> o < s>: Text ratllat < sup>: Superíndex < sub>: Subíndex < b> aplica negreta sense indicar cap importància semàntica. < strong> aplica negreta i indica que el text és important. < i> aplica cursiva sense implicar èmfasi. < em> aplica cursiva amb èmfasi, indicant que el text té importància.

Comentaris en HTML

Els comentaris en HTML són línies de text que s'afegeixen al codi per deixar notes o explicacions, però que no són visibles per als usuaris finals en la pàgina web. S’utilitzen per ajudar els desenvolupadors a documentar el codi, descriure seccions específiques o deixar indicacions per a futurs desenvolupadors. Els comentaris no afecten el rendiment ni la visualització de la pàgina en el navegador.
